# 每日奖励领取插件

安装并启用后，插件会自动把前端脚本加入当前主题配置。登录用户的页面左下角会显示固定的“领取流量”按钮，电脑与手机一致；未登录时不显示。点击按钮可随机减免已用流量。禁用时会自动移除该脚本。

## 安装

1. 在管理后台的“插件管理”中上传 `RewardClaim` 目录的压缩包，或将此目录保留在项目的 `plugins/` 下。升级现有版本时，上传版本号更高的 ZIP。
2. 安装插件，再启用插件。
3. 在插件配置中设置最小/最大奖励（MB）与领取间隔。

插件安装时会创建 `v2_reward_claims` 记录表。禁用插件后，悬浮入口和接口会停止加载；已领取记录不会被删除。

## 规则

- 默认每 24 小时可领取一次。最小与最大奖励可在插件配置中以 MB 设置；每次严格在当前保存的最小值与最大值之间等概率随机减免已用流量。减免会优先扣除下行流量，再扣除上行流量。
- 用户的已用流量少于最小奖励时不可领取，以确保实际减免值始终在已配置范围内。
- 已用流量介于最小值和配置最大值之间时，会以该用户的已用流量作为随机上限。例如范围设为 100 MB–200 GB、已用 500 MB，则随机范围为 100 MB–500 MB。
- 仅当前持有未到期的月付、季付、半年付、年付、两年付或三年付套餐的用户可领取。没有套餐、账号被禁用、套餐到期，以及不限时流量包用户均不可领取。
- 同一用户的领取请求以用户行锁串行化，重复点击或并发请求不会重复发奖。
- 奖励通过减少 `v2_user.u` 与 `v2_user.d` 实现：优先减去下行流量，再减去上行流量。
