# 每日流量

“每日流量”是一个登录后显示在用户页面左下角的悬浮插件。符合资格的用户可按后台设置的时间间隔领取奖励；每次奖励会随机减免已用流量，不增加套餐总流量。

## 安装与升级

1. 在管理后台“插件管理”上传 ZIP。打开 ZIP 后第一层应直接看到 `config.json`、`Plugin.php` 及各目录。
2. 安装并启用插件。
3. 在插件配置中设置随机奖励范围、领取间隔、弹窗标题与说明。
4. 用户登录后，左下角会显示“每日流量”按钮；未登录用户不会看到入口。

升级时请上传版本号更高的 ZIP。启用插件会自动注入悬浮入口；停用或卸载时会移除入口脚本。

## 后台配置

| 配置项 | 说明 |
| --- | --- |
| 最小奖励（MB） | 每次随机减免的最小已用流量。最小值至少为 1 MB。 |
| 最大奖励（MB） | 每次随机减免的最大已用流量。小于最小值时会自动按最小值处理。范围内按等概率随机。 |
| 领取间隔（小时） | 同一用户两次领取之间的最短间隔。最小 1 小时，最长 8760 小时。 |
| 奖励标题 / 奖励说明 | 显示在用户领取弹窗中的标题和说明。 |

## 可领取条件

用户必须同时满足以下条件：

- 账户正常，未被封禁；
- 当前套餐未到期；
- 当前套餐为月付、季付、半年付、年付、两年付或三年付周期套餐；
- 当前套餐存在该用户已完成支付的订单；
- 已用流量不少于后台设置的最小奖励；
- 已达到上一次领取后的领取间隔。

没有套餐、套餐到期、不限时套餐、流量包、试用套餐、手动分配但没有已完成支付订单的套餐，以及被封禁账户均不可领取。

## 奖励计算与发放

每次领取会在最小奖励与最大奖励之间等概率随机减免已用流量。

- 如果已用流量介于最小奖励和最大奖励之间，会将当前已用流量作为本次随机上限。
- 例如奖励范围设为 `100 MB - 2 GB`、当前已用流量为 `500 MB`，本次会在 `100 MB - 500 MB` 之间随机。
- 当前已用流量小于最小奖励时，不能领取，也不会产生领取记录。
- 发放时优先减少下行流量 `d`，不足部分再减少上行流量 `u`；两者不会变为负数。
- 该插件只减少已用流量，不增加套餐总流量，也不会修改套餐、到期时间或订阅链接。

## 并发与领取记录

同一用户的领取请求会使用用户行锁和最后领取记录锁串行处理。重复点击或并发请求不会重复发放奖励。

插件安装时创建 `v2_reward_claims` 表，记录用户 ID、实际减免字节数和领取时间。弹窗会显示最近 5 次领取的日期与减免流量；每次成功领取后，也会立即更新这份记录。

## 常见提示

| 提示 | 含义 |
| --- | --- |
| 暂不可领取 | 尚未达到领取间隔，或当前已用流量不足最小奖励。 |
| 仅已购买有效周期套餐的用户可以领取奖励 | 当前没有符合条件的已完成支付周期套餐订单。 |
| 仅未到期的周期套餐用户可以领取奖励；不限时流量包不可领取 | 当前套餐为不限时套餐、流量包或已到期套餐。 |
| 试用套餐不可领取奖励 | 当前套餐 ID 与系统 `try_out_plan_id` 一致；该判定优先于不限时套餐判定。 |

插件接口和悬浮入口在插件停用后不会加载；领取历史保存在 `v2_reward_claims` 中，可供后续审计。
