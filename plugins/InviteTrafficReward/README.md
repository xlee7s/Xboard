# 邀请奖励

“邀请奖励”是一个登录后显示在用户页面左下角的悬浮插件。用户每拥有一位有效邀请，即可领取一次奖励。奖励会根据领取人当前的套餐状态，发放不限时套餐、增加总流量、减免已用流量或延长套餐有效期。

## 安装与升级

1. 在管理后台的“插件管理”上传 ZIP；打开 ZIP 后第一层应直接看到 `config.json`、`Plugin.php` 及各目录。
2. 安装并启用插件。
3. 打开插件配置，完成“无套餐奖励的不限时套餐”等配置后保存。
4. 用户登录后，左下角会显示“邀请返利”悬浮按钮；未登录用户不会看到入口。

升级时请上传版本号更高的 ZIP。插件启用后会自动加载悬浮入口；停用或卸载时会移除入口脚本。

## 后台配置

| 配置项 | 说明 |
| --- | --- |
| 有效邀请起始日期 | 仅统计该日期 `00:00:00` 起注册的被邀请用户；更早注册的邀请永不计入奖励。格式为 `YYYY-MM-DD`。 |
| 每位邀请奖励流量（MB） | 每领取一位有效邀请对应的流量额度。用于无套餐首次领取后的总流量、不限时套餐用户增加的总流量，以及周期套餐的已用流量减免。 |
| 无套餐奖励的不限时套餐 | 必选。无套餐、套餐到期或试用套餐用户领取时发放的套餐。列表仅显示可一次性购买的不限时套餐，系统试用套餐不会显示。 |
| 延长一天所需流量（MB） | 仅用于周期套餐延期。延期时长 = 每位邀请奖励流量 ÷ 此值 × 1 天；可按小时精确折算。 |
| 奖励标题 / 奖励说明 | 显示在用户领取弹窗中的标题和说明。 |

未选择有效的不限时奖励套餐时，无套餐类型用户不能领取，已配置的有效邀请不会被消耗。

## 有效邀请规则

一位被邀请用户同时满足以下条件，才是一位有效邀请：

- `invite_user_id` 为领取人的用户 ID；
- 注册时间不早于后台设置的有效邀请起始日期；
- 当前未被封禁。

有效邀请不要求被邀请人购买套餐。每位被邀请用户只能被其邀请人领取一次；重复点击或并发请求不会重复发放奖励。

## 领取规则

### 无套餐、已到期或试用套餐

以下用户统一按“无套餐”处理：没有套餐、周期套餐已到期，以及当前 `plan_id` 等于系统 `try_out_plan_id` 的试用套餐用户。

- 只能领取后台选定的不限时套餐；
- 套餐只提供权限、分组、限速和设备数等套餐属性；
- 首次领取的总流量固定使用“每位邀请奖励流量”配置，不使用套餐本身的流量值；
- 发放时会将已用上行与下行流量归零，并把总流量设为该奖励额度。

试用套餐的判断优先于不限时判断：即使管理员将试用套餐设为不限时，它仍会按无套餐处理。

### 不限时套餐

当前持有任意不限时套餐（`expired_at` 为空）的用户，每领取一位有效邀请，都会增加一份后台设置的总流量。

- 不减免已用流量；
- 不要求已用流量达到奖励额度；
- 已有总流量会在原值上累加奖励额度。

### 未到期、非试用的周期套餐

当前持有未到期、且不是试用套餐的周期套餐用户，可在每次领取时任选一种方式：

1. **减免已用流量**：减免一份“每位邀请奖励流量”。只有当前已用流量不少于该额度时才可选择；余额不足不会消耗邀请。
2. **延长套餐有效期**：按“每位邀请奖励流量 ÷ 延长一天所需流量”折算延期秒数。该方式不要求已用流量充足。

每次领取可重新选择方式，不会影响之后的奖励。

## 奖励套餐切换

修改“无套餐奖励的不限时套餐”后，插件会在保存后的下一次站点请求中执行一次迁移：

- 所有当前 `plan_id` 仍等于旧奖励套餐 ID 的用户，会改为新的 `plan_id`；
- 只修改 `plan_id`；总流量、已用流量、到期时间、限速、设备数、分组和其他试用数据都不修改；
- 首次配置只记录当前套餐 ID，不会迁移任何用户。

请确认旧奖励套餐没有被用于不希望一同切换的其他用户，再切换配置。

## 用户页面与记录

领取弹窗显示：

- 已邀请、有效邀请、已领取、待领取数量；
- 最近 5 条邀请记录：被邀请邮箱（已遮罩）、注册时间和状态；
- 最近 5 条领取记录：被邀请邮箱（已遮罩）、领取时间和实际奖励方式。

正常可领取时，页面只显示一次规则说明。账户不可领取、没有待领取邀请，或周期套餐已用流量不足以减免时，才会额外显示状态提示。

## 数据与日志

插件安装时创建领取记录表 `v2_invite_traffic_reward_claims`。记录保存邀请人、被邀请人、领取方式、流量额度、延期秒数与领取时间；`invitee_user_id` 有唯一约束，防止同一邀请被重复领取。

奖励套餐切换或配置刷新失败会写入 Laravel 日志，可在站点的 `storage/logs/` 中排查。
