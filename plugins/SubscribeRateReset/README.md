# 订阅频率自动重置

当用户在设定时间窗口内频繁拉取订阅时，插件会自动生成新的订阅 token，使旧订阅链接失效。

## 配置说明

- **启用插件**：关闭时不会计数或重置。
- **统计时间（分钟）**：例如设为 `5`，表示只统计连续 5 分钟内的请求。
- **触发次数**：例如设为 `3`，表示窗口内第 3 次有效订阅请求时重置 token。
- **排除用户 ID / 排除邮箱**：匹配任一项的账户永不计数、永不重置。支持换行、英文或中文逗号、分号分隔。
- **记录重置日志**：重置时写入应用日志，不记录完整 token。

## 工作方式

插件挂载在正常订阅请求流程中，只处理已通过账户可用性检查的订阅请求。达到阈值后，当前请求仍会正常返回订阅内容，但从下一次请求开始，客户端必须使用新的订阅链接。

计数数据保存在项目当前配置的 Laravel 缓存中；计数到达阈值或缓存窗口到期后会清除。清理缓存或更换缓存驱动会使未完成的窗口计数失效。
