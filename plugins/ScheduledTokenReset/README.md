# 分批定时重置订阅链接

此插件会按设定计划，为符合条件的用户重新生成订阅 `token`。它**不会修改 UUID**，因此不会变更节点认证 UUID 或其他依赖 UUID 的功能。

## 工作方式

1. 启用后，插件会在下一次调度（通常 1 分钟内）启动第一轮重置。
2. 每分钟只处理“每分钟重置数量”指定的一小批用户，使用游标续跑直至全部完成。
3. 整轮完成后记录完成时间，等待“完整重置间隔（分钟）”后立即启动下一轮。

## 安全规则

- 插件默认关闭。
- 默认排除管理员账户。
- 可按用户 ID 或邮箱永久排除账户；两项是或关系。
- 可选仅重置有效用户：未封禁、有可用流量、未过期或长期有效。
- 对每批用户使用数据库事务和缓存锁，避免多个调度器重复处理。

## 重要影响

重置后，旧订阅链接会失效。用户需要从仪表盘获取并重新导入新的订阅链接。请先在测试账户和小批量配置中验证，再面向所有用户启用。

进度存储在项目缓存中。清除缓存会丢失当前游标，使未完成的轮次在下次启动时可能从头开始，因此批量执行期间请避免清理缓存。
